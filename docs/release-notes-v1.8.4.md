# 1.8.4 版本更新报告（相对 1.7 基线）

> 基线：v1.7（versionCode 8，用户实机使用版本）
> 目标：v1.8.4（versionCode 13，最新候选包，尚未正式发布）
> 说明：1.8.1 / 1.8.2 / 1.8.3 均为未正式发布的中间候选，其功能已并入 1.8.4 安装包，本报告统一汇总 1.7 → 1.8.4 的全部变化。

---

## 一、问题修复内容

### 1. 稳定性与数据修复

- 修复托管详情滑到底部闪退：加入稳定列表 key 与高密度详情往返滚动回归，消除键冲突导致的崩溃风险。原设备根因尚未复现，仍需实机反复滚动确认。
- 修复托管批量完成后备份无法恢复：兼容旧备份，同时保存打卡与任务编号并校验归属一致，保留批量撤销历史。
- 修复零价及改价后超收备份无法恢复：修复 schema12 兼容旧备份的可空字段，杜绝合法零价 / 多收订单被误拒。

### 2. 体验与交互纠正（结合用户反馈）

- 修复今日事项顶部拥挤、任务色设计不合理：精简顶部布局，把颜色设置从今日页迁出，改到订单详情内直接选色。
- 修复任务面板 / 老板界面单元过大：改为默认折叠，只露标题，点开再展示细节与操作，显著减少滚动。
- 修复订单管理修改入口分散：合并为统一的「修改」+「作废订单」入口，一个界面集中完成名称、日期、价格、备注、收款方式、任务等全部更正。
- 修复模板区服预设遗漏：游戏模板补上区服预设，建号时下拉选择并保留手填。
- 优化整体字体与排版：统一字号层级（标题 22sp / 单元 16sp / 正文 15sp / 辅助 13sp）、对齐留白与触控尺寸。

### 3. 更新服务与更新流程修复

- 修复发布逻辑缺陷：解决「暂存 → 激活丢失远程下载地址」与「远程发布误走本地字节」两项阻断，改为不可变发布库，激活前回下载校验，失败自动回退上一版本。
- 更新流程改为浏览器下载：新增版本更新弹窗，「下载更新」经系统浏览器打开 Pgyer 官方页，绕过应用内下载 / 进度 / 校验 / 自动安装，避免系统安装授权与校验的链路问题。

---

## 二、新增功能

### 本版本（1.8.4 阶段）核心新增

- 打卡式托管：新增按约定次数累计完成的托管方式，无起止日期，同一天允许多轮，每轮全部子任务完成计一次；配套轮次表持久化。
- 订单颜色标记：颜色归属到订单级，订单详情顶部直接选色；今日支持「全部 / 未着色 / 按颜色」筛选，整单颜色统一下发到未标记任务。
- 模板区服预设 + 账号下拉：模板编辑内区服增改删，账号表单新增下拉选择并保留手填。
- 模板与订单功能同步：模板可选服务模式与目标次数，建单带入，导入导出与备份目录已接入；新建不复制运行进度。
- 已归档老板删除：归档态提供删除入口、影响预览与确认，事务级联删除账号及派生记录，提交后清理附件。
- 服务模式下沉到分类：模板分类与草稿各自携带服务模式 / 次数，分类共识与订单镜像一致。
- 窄屏底部导航合并「设置」：适配小屏，将设置入口并入底部导航。
- 更新服务不可变发布库：版本 / 大小 / 哈希 / 签名绑定同一 APK，激活前校验、失败回退，保证更新分发一致性。
