# v1.8.5 更新说明

日期：2026-10-24。版本：1.8.5 / versionCode 14。

本说明记录相对已发布 v1.8.4 的新增与修复。双端实现和本机集成范围已通过独立审查；物理手机安装、覆盖升级及实际体验仍待验证。本次版本调整不代表已发布或部署。

## 网页端与安卓端备份互通

- 支持本轮配套安卓与网页版通过 `.dgbk` 完整备份双向转移资料：安卓导出后在网页恢复并继续操作，再从网页导出回安卓；反向流程同样支持。
- 保留老板、账号、分类、订单、模板、任务进度、托管期次与打卡轮次、累计记录与更正历史、收款流水、颜色和截图附件。已在浏览器与安卓模拟器中核对业务内容及真实图片字节。
- 明文备份、密码加密备份和含中文等 Unicode 字符的密码均已验证。模板独立文件升级为格式 4，支持双向导入、建单使用和再导出。
- 支持读取旧版安卓 schema-14 及受支持的旧网页备份；当前写出 schema-15。未升级的旧安卓 v1.8.4 不作为新备份的接收端。
- 联动采用手动导出、传递文件、恢复；没有账号云同步、自动同步或两端资料自动合并。恢复会替换接收端当前整份资料，请先备份；建议一次在一端继续编辑，切换前传递最新备份。
- 网页资料保存在对应浏览器和网站域名下；换浏览器、设备或域名，需要通过备份转移。提醒投递状态和设备身份等本机状态按接收设备重建。

## 三项主要功能

### 模板预设订单名称（UF-036）

- 模板可保存默认订单名称，建单选择模板后自动带入，仍可按本单修改。
- 手动标题与自动带入标题按来源处理，切换模板遵循既定规则；改模板不重命名已有订单。
- 默认标题与模板服务配置、任务口径及区服选项可跨端保留；修复安卓模板界面导入丢失区服选项的问题。

### 账号视图与自定义分类（UF-037）

- 保留老板视图，增加跨老板的账号视图与自定义分类。
- 支持新建、选择、改派、重命名和删除分类，账号表单中可直接创建分类。
- 删除分类只将账号转为未分类，不删除账号、订单或历史；同名账号通过独立身份区分。
- 分类与账号归属随完整备份互通，视图偏好保存在本机。

### 数值跨日累计（UF-038）

- 新增明确的累计总值口径：先记 10、再记 15，当前值为 15；跨日后保留，同一目标在有效服务范围内可继续更新。
- 普通逐次、每日及周期目标保持原有规则，不会全部改成跨日累计。
- 保留每次记录与日期，支持追加式更正和撤销；更正旧日期不会覆盖更晚日期的有效总值。
- 短期单、按日期托管和按次数托管分别隔离累计范围；续期与新轮次按各自目标起始值处理。
- 批量完成跳过未达标累计任务，不虚构累计值；已移除任务保留历史应做责任，并提供合法历史更正或补记入口。

## 计次与恢复可靠性修正

- 保留同一天多轮打卡的独立身份；按期次保存目标与任务名单，读页面不凭空创建轮次。
- 修复同日续期服务起点、最新期次目标镜像、历史轮次重开和成功命令重试等边界问题。
- 按任务所属期次的游戏时区、刷新点、服务星期和生效区间校验进度；保留归档、作废和旧资料代次守卫。
- 修复网页 ZIP 压缩条目与安卓读取不兼容、安卓恢复空值写入、自引用外键行顺序依赖及短期单批次缺少游戏日的问题。
- 对错误密码、篡改文件、缺失或损坏附件、无效关联和恢复写入失败等情况执行拒绝与原资料保留验证。
